# 📝 Changelog

Todas as mudanças importantes deste projeto serão documentadas neste arquivo.

## [3.0.0] - 2026-05-21

### ✨ Adicionado
- Sistema completo de autenticação OAuth 2.0 com Google
- Backup e restauração de dados no Google Drive
- Search & Filter avançado em tempo real
- Sistema de 10 Badges/Achievements gamificados
- Animações de números (contadores suaves)
- Exportação em CSV e PDF
- Service Worker para suporte offline
- Progressive Web App (PWA) com manifest
- Dark mode / Light mode toggle
- Validação de dados no backend
- Toast notifications elegantes
- Gráficos interativos (Chart.js)
- Suporte responsivo mobile-first

### 🔒 Segurança
- Sessions com httpOnly cookies
- Proteção CORS
- Validação de inputs no backend
- Sanitização de HTML
- Variáveis de ambiente para credenciais

### 🎨 UI/UX
- Interface moderno com CSS variables
- Animações smooth (slideIn, bounce, pulse)
- Dark/Light mode automático
- Ícones emojis para melhor visualização
- Feedback visual para todas as ações

### 📱 Mobile
- Layout 100% responsivo
- Touch-friendly buttons (44px mínimo)
- Menu lateral colapsável
- Suporte para installação em celular
