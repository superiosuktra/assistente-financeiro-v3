# 🐛 Encontrou um bug?

## Antes de reportar

1. ✅ Verifique se o bug já foi reportado em [Issues](https://github.com/superiosuktra/assistente-financeiro-v3/issues)
2. ✅ Tente recarregar a página (Ctrl+Shift+R)
3. ✅ Limpe cache/localStorage se necessário
4. ✅ Teste em incógnito ou outro navegador
